# License Activation

## Activating Your License

1. Open Sutto preferences:
   - Click the settings icon in the main panel footer, **OR**
   - Open GNOME Extensions app → click the settings icon on Sutto
2. Go to the **License** section
3. Enter your license key and click Activate
4. After successful activation, the status shows your "Valid until" date

## Troubleshooting

### "License key not found"

The entered key is invalid. Double-check that you copied the full license key from your purchase confirmation email.

### "Subscription has expired"

Your subscription period has ended. Renew your subscription to continue using Sutto.

### "Subscription was cancelled"

Your subscription has been cancelled and is no longer active. To continue using Sutto, [purchase a new license](/pricing).

### "Couldn't reach the license server. Try again later."

Sutto got no answer from the license server. Check your network connection and try again later. Nothing changes on your device: a trial stays a trial. If the problem persists, the server may no longer be operational. A valid license keeps working while the server does not answer. A trial that has ended stays locked while the server is running. Once the server no longer answers, Sutto works again the next time it starts (for example, when you log in or unlock the screen), so Sutto never stops working because the server was shut down.

### Device Limit

Each license supports up to **3 device activations**. If you activate on a 4th device, the oldest activation is automatically deactivated.

### Offline Usage

Sutto works offline for up to **7 days** after the device was last online. After that, an internet connection is needed to continue.
